# 📊 Medical Insurance Cost Dashboard

🇺🇸 English · [🇧🇷 Português](./README.md)

Interactive data analysis and visualization project built with **Python, Pandas, Matplotlib, Seaborn, and Streamlit** to explore the factors associated with medical insurance costs.

## 🎯 About the Project

This project analyzes a healthcare insurance dataset to investigate how demographic and behavioral characteristics are associated with medical costs.

The analysis focuses mainly on:

* age;
* body mass index (BMI);
* smoking status;
* region;
* number of dependents;
* insurance charges.

The goal is to transform raw data into **visualizations and insights that make it easier to understand the main factors associated with healthcare costs**.

## 📊 Main Analyses

* Comparison of medical costs between smokers and non-smokers;
* Relationship between BMI and insurance charges;
* Impact of age on medical costs;
* Comparison of costs across regions;
* Analysis of key indicators and data distributions;
* Interactive exploration using filters and visualizations.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/warleyroma/medicalcost_dashboard.git
cd medicalcost_dashboard
```

### 2. Install the dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the dashboard

```bash
streamlit run app.py
```

Streamlit will make the dashboard available in your browser.

## 📂 Dataset

This project uses the public **Medical Cost Personal Datasets**, available on Kaggle.

Source:

[Medical Cost Personal Datasets — Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance)

## 🔎 Key Questions

* Do smokers have significantly higher medical costs?
* How do medical costs vary with age?
* Is there a relationship between BMI and medical expenses?
* Are there relevant differences between regions?
* Which characteristics are most associated with higher insurance costs?

## ⚠️ Disclaimer
